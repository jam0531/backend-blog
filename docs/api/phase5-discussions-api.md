# 评论与留言

公开接口：GET/POST `/api/blogs/{id}/comments`，GET/POST `/api/messages`。管理接口：GET `/api/admin/comments`、GET `/api/admin/messages`；两类资源均支持 DELETE `/{id}` 和 POST `/{id}/replies`。

- 公开 GET 接收 page、size，size 最大 100；仅分页根话题，每个根的 replies 平铺全部后代，parentId/replyTo 保留实际回复对象。根按创建时间及 ID 倒序，回复正序。total 是根数量。管理列表分页全部记录，total 包含回复。
- 留言 messageType 为 0（普通留言）或 1（友链交流），默认 0；管理列表不传类型时查全部。评论管理可按 blogId 筛选。
- 公开 POST 接收 nickname、email、content、可选 parentId；留言额外接收 messageType。昵称/邮箱最多 255 字，邮箱必填并校验格式；内容纯文本、非空、最多 5000 字。管理回复只接收 content。
- 文章须已发布才能公开读取或发表；关闭评论时公开 POST 返回 409，GET 仍显示原评论。后台管理员可回复已关闭评论的文章。未发布文章的公开评论 GET 返回 404。
- 父评论必须属于该文章；父留言必须具有相同 messageType。管理员标识、头像和管理回复昵称由服务端账号决定，忽略客户端伪造身份。
- 公开响应没有 email。ID、blogId、parentId 均为字符串，根 parentId=null。管理列表才包含邮箱；前端使用文本插值，不渲染内容为 HTML。
- 所有 POST/DELETE 要求会话 CSRF；评论、留言及后台回复共用 15 秒会话限频，成功提交后计时，超限返回 429，失败不占用间隔。这是单会话限制，不宣称可阻止攻击者更换会话。
- 删除评论/留言同时删除同一文章或同一类型内的全部后代；删除文章会删除全部评论。写入事务使用 READ_COMMITTED，并与删除共同锁定文章/留言根记录，避免等待锁后读取旧快照而产生孤立回复。

本地验证：用户授权 2 篇临时文章、6 条评论和 6 条留言。已验证根分页、多层回复、跨归属拒绝、身份防伪、公开邮箱隐藏、纯文本、共享限频、关闭评论后的管理员回复、未发布隐藏、子回复/根话题删除和文章级联清理。后台回复通过页面实际发表。清理后四张相关表完整指纹与联调前一致；未编写测试文件。未做多进程并发压测或生产验证。
